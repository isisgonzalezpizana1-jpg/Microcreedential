# Vector Hunt Physics Game

Vector Hunt is a one-file HTML/JavaScript Canvas game inspired by Duck Hunt. It includes two playable modes:

- Duck Hunt Mode
- Orbital Mode

The game demonstrates physics concepts for the PEG microcredential, including vectors, velocity, acceleration, forces, momentum, collisions, and orbital mechanics.

## How to Play

Open `index.html` in a browser.

### Duck Hunt Mode

- Move the mouse to aim.
- Click to shoot.
- Hit ducks to score points.
- Choose a Target Score: 50, 100, 150, or 200.
- The game ends when the player reaches the Target Score or time runs out.

### Orbital Mode

- Click `Mode: Duck Hunt` to switch to `Mode: Orbital Mode`.
- Aim at robotic space ducks.
- Click to fire one laser at a time.
- The laser curves because of gravity from the black hole.
- Hit robotic ducks to score points.
- The game ends when the player reaches the Target Score or time runs out.

## Physics Concepts

- Dynamics: `F = m*a`
- Collisions: conservation of momentum
- Inelastic collision between projectile and duck
- Orbital Mechanics: `F = G(m1*m2)/r^2`
- Velocity vectors: `vx`, `vy`, and speed
- Gravity, wind, and acceleration

## Deployment

This project is ready for GitHub Pages. Upload `index.html` to a public GitHub repository and enable GitHub Pages from the repository settings.
